Importa Libri da Desktop

Carica il file libri.json generato dalla versione desktop per importare tutti i libri nel database online.

Il file si trova nella cartella dove hai avviato l'applicazione desktop
Annulla

Come trovare il file libri.json:

  1. Apri il Finder (Mac) o Esplora File (Windows)
  2. Vai nella cartella dove hai avviato l'applicazione desktop
  3. Cerca il file libri.json
  4. Selezionalo e caricalo qui sopra
